# HeRo Sim (Web-Version)

Passwortgeschützte Spielversion für Browser und iPhone (zum Home-Bildschirm hinzufügen).
Das Spiel ist verschlüsselt (AES-256-GCM, Schlüssel per PBKDF2 aus dem Passwort) – ohne Passwort lässt es sich nicht starten.
Der Quellcode liegt nicht hier. Gebaut mit `tools/pages/build-pages.mjs` aus dem Spielprojekt.
